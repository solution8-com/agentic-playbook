# S8 Agentic Playbook - Skills

The Solution8 skills pack for Claude Code: 25 skills covering the full agentic
workflow - planning, building, verifying, shipping.

## Install

Run from the repo the skills should work in (skills install per repo, not globally):

```
npx skills add solution8-com/INT-s8-agentic-playbook
```
